Skill Gap Analysis

Team Skills vs. Data Analyst -> Data Scientist Market Requirements

Overview

This page compares our team’s current skill levels against the core skills expected for the Data Analyst -> Data Scientist / Analytics Engineer pathway inside NAICS 5182, and proposes a concrete improvement plan for closing the gaps.

Team Skill Levels

Each team member self-rated their current proficiency on a 1-5 scale:

  • 1 = Beginner
  • 2 = Basic knowledge
  • 3 = Intermediate
  • 4 = Advanced
  • 5 = Expert

Comparing Team Skills to Industry Requirements

The core skills most associated with the Data Analyst -> Data Scientist pathway are Python, SQL, Machine Learning, Cloud Computing (AWS), Data Visualization, and Statistics – consistent with the role types (Data Analyst, Data Engineer, Data Scientist, ML Engineer) already identified in our EDA page.

Note: we did not derive this list by counting the skills field in our processed dataset – that field is truncated to only the first few skills alphabetically for each posting (every one of the top 20 most-frequent values in that field started with “A” or “B”, which is a data artifact, not a real signal), so a raw frequency count from it would be misleading.

top_skills = ["Python", "SQL", "Machine Learning", "Cloud/AWS", "Data Visualization", "Statistics"]

team_avg = df_skills[top_skills].mean().round(2)
team_min = df_skills[top_skills].min()

gap_df = pd.DataFrame({
    "Team Average": team_avg,
    "Team Minimum": team_min,
    "Target (Advanced)": 4,
})
gap_df["Gap to Target (avg)"] = (gap_df["Target (Advanced)"] - gap_df["Team Average"]).round(2)

Machine Learning and Data Visualization sit close to target on average, but with real variance between members.

Improvement Plan

Based on the gaps above, each member’s priority differs:

  • Manan Patel – priority: Statistics (currently 2). Strong in Python/SQL already, so the highest-leverage next step is building statistical foundations (hypothesis testing, regression) rather than more programming practice.
  • Richard Park – priority: Python and Data Visualization (both at 3). Already strong in Cloud/AWS and Statistics, so pairing with Manan or Michael on Python-heavy analysis tasks would close this gap fastest.
  • Michael Phillips – priority: Cloud/AWS (currently 3), despite being the team’s strongest in ML and visualization. Cloud skills are directly tied to the “Data Processing, Web Hosting” industry scope of this whole project, making this a high-relevance gap to close.

Team-wide priority: Statistics is the one area where every member is below “Advanced,” making it the single highest-leverage shared investment – a short structured course (e.g. a statistics-for-data-science module) benefits all three members at once, versus the other skills where pairing/mentoring between members who are already strong is more efficient than external coursework.
