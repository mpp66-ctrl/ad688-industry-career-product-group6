Skill Gap Analysis

Team Skills vs. Data Analyst -> Data Scientist Market Requirements

Overview

This page compares our team’s current skill levels against the core skills expected for the Data Analyst -> Data Scientist / Analytics Engineer pathway inside NAICS 5182, and proposes a concrete improvement plan for closing the gaps.

Team Skill Levels

Each team member self-rated their current proficiency on a 1-5 scale:

  • 1 = Beginner
  • 2 = Basic knowledge
  • 3 = Intermediate
  • 4 = Advanced
  • 5 = Expert

Comparing Team Skills to a Planning Benchmark

For this preliminary scorecard, the team selected Python, SQL, Machine Learning, Cloud/AWS, Data Visualization, and Statistics as relevant skill areas for the pathway. These are working categories, not a ranking of observed employer demand. Before the final submission, we will support the selection with cited occupational sources or complete posting-level evidence and distinguish requirements across the three target roles.

The target of 4 (Advanced) is a team-selected development goal for comparison, not an employer-validated threshold or a measure of hiring readiness. Self-ratings are subjective; each member should confirm their ratings and support them with a project or work example. The averages summarize this small team’s responses and should not be interpreted as an individual candidate’s proficiency.

Note: we did not derive this list by counting the skills field in our processed dataset – that field is truncated to only the first few skills alphabetically for each posting (every one of the top 20 most-frequent values in that field started with “A” or “B”, which is a data artifact, not a real signal), so a raw frequency count from it would be misleading.

top_skills = ["Python", "SQL", "Machine Learning", "Cloud/AWS", "Data Visualization", "Statistics"]

team_avg = df_skills[top_skills].mean().round(2)
team_min = df_skills[top_skills].min()

gap_df = pd.DataFrame({
    "Team Average": team_avg,
    "Team Minimum": team_min,
    "Planning Target (Advanced)": 4,
})
gap_df["Gap to Target (avg)"] = (gap_df["Planning Target (Advanced)"] - gap_df["Team Average"]).round(2)

A negative gap indicates an average above the target, not a skill deficit. Individual ratings remain important: a team average at or above 4 can still hide a member’s gap.

Limitations and Next Steps

  • Confirm every member’s self-ratings, particularly ratings of 5 (Expert), using concrete evidence.
  • Validate the skill categories using cited occupational sources or complete posting text; the truncated skills field cannot support a market-demand ranking.
  • Separate skill expectations for Data Analyst, Data Scientist, and Analytics Engineer rather than assuming one Advanced threshold fits all roles.
  • Review the proposed milestones together and reassess individual gaps after the deliverables are completed.
